# Paper Source

The active coverage/PTE reproducibility archive is stored at the repository root through `configs/`, `scripts/`, `outputs/`, and `figures/coverage_robustness/`.

The current final manuscript TeX source is not included in this local release snapshot. Older morphology matched-null draft material has been moved to `archive/old_manuscripts/` so it is not confused with the active coverage/PTE analysis.

Before journal submission, place the final manuscript source here, for example:

```text
paper/starlink_uemr_multistage_QA.tex
paper/starlink_uemr_refs.bib
```

The manuscript Data and Code Availability statement should point to this `starlink_uemr` repository as the single source of record for the active analysis.
