## 2. Multi-Satellite Intrinsic Phase Check

Comparison model:

```text
V_sat = sum_s A_s(t,nu) exp(2 pi i nu tau_s(t) + i theta_s),
theta_s ~ Uniform(0, 2 pi)
```

Implementation:

- `compute_tail_case(...)` now accepts `intrinsic_phase_seed`.
- When supplied, each injected satellite visibility is multiplied by one fixed
  random complex phase before the observed injected visibility is summed.
- The matched-null ensemble is still generated by per-satellite global phase
  randomization around that injected model.

Run:

- Output: `coverage_absint_tail_refined_pte003_brel1e3_random_phase.csv`
- Summary: `coverage_absint_tail_refined_pte003_brel1e3_random_phase_summary.csv`
- Phase seed base: `20260709`

Summary:

| metric | coherent default | random intrinsic phase |
| --- | ---: | ---: |
| rows after paired-beam expansion | 10 | 10 |
| `PTE_global,max < 0.01` after `N_null=1000` | 0 | 0 |
| `PTE_global,absint < 0.01` and `B_rel > 1e-3` | 3 | 0 |
| beam-robust absint candidates | 0 | 0 |

The frozen-only absint rows that survived under the coherent default all become
non-significant under one random intrinsic-phase draw:

| case | `PTE_absint^1000`, coherent | `PTE_absint^1000`, random phase |
| --- | ---: | ---: |
| frozen smooth multi | 0.0060 | 0.6733 |
| frozen lines multi | 0.0080 | 0.5544 |
| frozen khz_comb multi | 0.0080 | 0.6264 |

Conclusion:

The integrated-power excesses are not robust to random per-satellite intrinsic
phases. This supports treating the coherent multi-satellite sum as a conditional
stress test rather than as a phase-agnostic detection claim.
